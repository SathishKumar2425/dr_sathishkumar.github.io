# Dr. Sathish Kumar — GitHub Pages Website

This folder is a complete static academic/research portfolio website.

## Files
- `index.html` — main website
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — profile image
- `assets/Dr-Sathish-Kumar-CV-2026.pdf` — CV download

## Publish on GitHub Pages

1. Create/sign in to your GitHub account.
2. Create a new repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
3. Upload **all files and folders inside this package**.
4. In GitHub, open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then Save.
7. After GitHub publishes it, your site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io`

## Before publishing
Review the contact information and academic details. The website intentionally does not publish personal CV details such as date of birth, family information, or residential address.
